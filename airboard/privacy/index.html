AirBoard

개인정보 처리방침

최종 수정일: 2026-10-01
시행일: 2026-10-01

AirBoard(이하 "앱")는 개발자에게 어떤 개인정보도 보내지 않습니다. 앱에는 분석·광고·오류 수집 도구가 없고, 개발자가 운영하는 서버도 없습니다.

앱은 내 폰 안에서 작은 웹 서버를 켜서, 같은 Wi-Fi(또는 폰 핫스팟)에 연결된 다른 기기와 사진·영상·파일·글을 주고받게 해 줍니다. 주고받는 내용은 폰과 그 기기 사이에서만 오가며, 인터넷이나 클라우드를 거치지 않습니다. 아래에 무엇이 어디에 저장되는지 그대로 적었습니다.

1. 수집하는 개인정보

개발자가 수집하는 것

없습니다. 이름, 이메일, 전화번호, 위치, 연락처, 광고 식별자, 사용 기록, 오류 기록을 포함해 어떤 정보도 개발자에게 전송되지 않습니다.

내 폰 안에만 저장되는 것

항목저장 위치쓰는 목적
내가 공유한 사진·영상·파일·클립보드 글폰의 앱 전용 저장공간같은 네트워크의 다른 기기에 보여 주기
다른 기기에서 올린 파일과 글폰의 앱 전용 저장공간폰 화면에 보여 주기
'저장'을 누른 파일폰의 다운로드/AirBoard 폴더사용자가 직접 보관
다른 기기가 올린 파일의 올린 기기 IP 주소와 시각폰의 앱 전용 저장공간(서버 기록)올린 사람이 12시간 안에 직접 지울 수 있게 하기

다른 기기의 브라우저에 저장되는 것

웹 보드를 연 브라우저에는 그 기기에서 정한 기기 이름, 카드 위치, 화면 테마, 내가 올린 파일 목록이 저장됩니다(브라우저의 로컬 저장소). 이 정보는 그 브라우저 밖으로 나가지 않습니다.

2. 누가 볼 수 있나요

서버가 켜져 있는 동안에는 같은 네트워크에서 화면의 주소를 아는 사람 누구나 공유한 내용을 보고 파일을 올릴 수 있습니다. 접속 비밀번호는 없습니다. 카페·공항 같은 공용 Wi-Fi에서는 다 쓰고 나서 서버를 꺼 주세요. 서버를 끄면 다른 기기에서 더 이상 접속할 수 없습니다.

3. 보관 및 삭제

  • 앱에서 항목의 휴지통을 누르면 바로 지워집니다.
  • 다른 기기에서 올린 사람은 12시간 동안 웹 보드에서 직접 지울 수 있습니다.
  • 앱을 삭제하면 앱 전용 저장공간의 내용과 서버 기록이 모두 지워집니다. 다운로드/AirBoard 폴더에 '저장'한 파일은 사용자의 파일이므로 남습니다.
  • 브라우저에 저장된 정보는 그 브라우저의 사이트 데이터를 지우면 사라집니다.

4. 제3자 제공

개발자는 어떤 정보도 받지 않으므로 제3자에게 제공하는 정보도 없습니다. 앱은 Google Play를 통해 배포되며, Google Play가 앱 설치와 관련해 처리하는 정보는 Google의 개인정보처리방침을 따릅니다.

5. 분석 및 광고

앱에는 분석 도구와 광고가 없습니다.

6. 아동 개인정보

앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

7. 권한별 사용 목적

권한쓰는 목적
인터넷(INTERNET)폰 안에서 웹 서버를 켜고 같은 네트워크의 기기와 주고받기
네트워크·Wi-Fi 상태 확인접속 주소와 QR을 만들고, Wi-Fi·핫스팟 연결 여부 확인
포그라운드 서비스(데이터 동기화)서버가 켜져 있는 동안 알림을 띄우고 계속 동작하기
화면 꺼짐 중 동작 유지(WAKE_LOCK)화면이 꺼져도 서버가 멈추지 않게 하기
알림서버가 켜져 있음을 알리고, 자동으로 꺼졌을 때 알리기
저장공간 쓰기(Android 9 이하에서만)'저장'을 누른 파일을 다운로드 폴더에 넣기

사진·영상을 고를 때는 Android의 사진 선택 화면을 쓰므로, 앱이 사진첩 전체를 읽는 권한은 요청하지 않습니다. 사용자가 고른 항목만 앱으로 전달됩니다.

8. 오픈소스

앱은 오픈소스 파일 서버 copyparty를 바탕으로 만들었습니다. 사용한 오픈소스와 라이선스는 앱의 정보 화면에서 볼 수 있습니다.
